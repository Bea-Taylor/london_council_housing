# London Council Housing 

This repo contains the code to recreate the analysis and figures included in this blog post about the london council hosuing crisis: [https://citymodellinglab.uk/blog/posts/small_council_housing/small_council_housing.html](https://citymodellinglab.uk/blog/posts/small_council_housing/small_council_housing.html). 

## Data 

The data used here comes from: 
* Planning London Datahub 
    - Planning applications for residential units 
* London Datastore 
    - Local authority district boundaries 
    - Opportunity areas, as defined in the London Plan 2021
* gov.uk 
    - Live tables on homelessness [https://www.gov.uk/government/statistical-data-sets/live-tables-on-homelessness](https://www.gov.uk/government/statistical-data-sets/live-tables-on-homelessness)
